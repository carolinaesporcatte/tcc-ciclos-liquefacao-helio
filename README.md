# Modelagem de Ciclos de Liquefação de Hélio
Este repositório contém os códigos desenvolvidos para o Trabalho de Conclusão de Curso em Engenharia Mecânica, voltado à modelagem e análise termodinâmica de ciclos de liquefação de hélio baseados no ciclo de Collins.

## Códigos disponíveis
- `ciclos de Collins sem pre-resfriamento.py`: modelo do ciclo de Collins sem pré-resfriamento com nitrogênio líquido.
- `ciclo com pre-resfriamento-modelo A.py`: modelo do ciclo de Collins com uma etapa de pré-resfriamento com LN2.
- `ciclo com pre-resfriamento-modelo B.py`: modelo do ciclo de Collins com duas etapas de pré-resfriamento com LN2.

## Ferramentas utilizadas
Os modelos foram desenvolvidos em Python, utilizando principalmente:
- TESPy
- Exerpy
- CoolProp
- NumPy
- Matplotlib

## Objetivo
Os códigos permitem avaliar parâmetros de desempenho como fração liquefeita, potência líquida, OP e eficiência exergética dos ciclos analisados.
